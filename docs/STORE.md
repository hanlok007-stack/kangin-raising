# Google Play 출시 안내

앱 파일과 등록 자료는 준비돼 있다. 아래에서 **[직접]** 표시가 붙은 일은 계정 주인만 할 수 있다(계정 생성, 결제, 본인 확인, 비밀번호, 최종 제출).

## 0. 지금 상태

| 항목 | 상태 |
| --- | --- |
| 디버그 APK (휴대폰에 바로 설치) | `C:\Users\eetlk\android-dev\kangin-debug.apk` |
| 출시용 AAB | `C:\Users\eetlk\android-dev\kangin-release.aab` — 서명 키를 만든 뒤 다시 빌드해야 올릴 수 있다 |
| 패키지 이름 | `io.github.hanlok007stack.kangin` (한번 올리면 바꿀 수 없다) |
| 버전 | 1.0.0 (versionCode 1) |
| 대상 API | 36 (Play의 신규 앱 요건 충족) |
| 실제 광고·결제 | 아직 없음. 광고 자리는 3초 대기 화면, 구매 버튼은 "출시 후 구매 가능" 안내만 나온다 |

## 1. 휴대폰에서 먼저 해 보기 **[직접]**

1. `kangin-debug.apk`를 휴대폰으로 옮긴다(카카오톡 "나에게 보내기", USB, 구글 드라이브 등).
2. 휴대폰에서 파일을 열어 설치한다. "출처를 알 수 없는 앱" 경고가 나오면 허용한다.
3. 확인할 것: 가로 화면 고정, 글자 크기, 버튼이 손가락으로 눌리는지, 세이브가 앱을 껐다 켜도 남는지.

## 2. 서명 키 만들기 **[직접, 한 번만]**

```bash
npm run app:key
```

비밀번호를 직접 정해 입력한다. `android\upload-keystore.jks`와 비밀번호는 **따로 백업**해 둔다. 그다음 서명된 AAB를 만든다.

```bash
npm run app:release
```

## 3. Play 개발자 계정 **[직접]**

1. https://play.google.com/console 에서 개발자 계정을 만든다. 등록비 미화 25달러(1회), 본인 확인(신분증)이 필요하다.
2. **개인 계정은 바로 공개 출시가 안 된다.** 비공개 테스트를 테스터 12명 이상으로 14일 넘게 돌려야 프로덕션 신청이 열린다. 가족·친구 12명의 구글 계정 이메일을 미리 모아 두면 빠르다. (이 요건은 구글이 가끔 바꾼다. Console에 뜨는 안내가 기준이다.)

## 4. 앱 만들기와 스토어 등록정보

Play Console → 앱 만들기에서 아래 내용을 붙여 넣는다.

- **앱 이름**: 이강잉 키우기
- **기본 언어**: 한국어
- **앱/게임**: 게임 · **무료/유료**: 무료
- **카테고리**: 시뮬레이션 (스포츠도 가능)

**간단한 설명** (80자 이내)

```
슛둥이 꼬마를 은퇴까지. 훈련, 이적, 연봉 협상, 대표팀. 선택마다 인생이 갈리는 축구선수 육성 패러디.
```

**자세한 설명**

```

이 아이가 세계적인 선수가 될지, 태권도 국가대표가 될지, 먹방 유튜버가 될지는 당신의 선택에 달렸습니다.

■ 키우기
· 훈련과 생활을 골라 일정을 짭니다. 같은 훈련을 반복하면 경기에서 쓸 기술을 배웁니다.
· 훈련만 시키면 아이가 딴마음을 먹습니다. "태권도 선수가 될래요."

■ 경기
· 결정적 순간마다 직접 고릅니다. 슛, 패스, 드리블, 그리고 배운 기술.

■ 프로의 세계
· 해마다 연봉 협상, 계약이 끝나면 FA 시장.

■ 대표팀과 인생

· 가족, 동료, 그리고 관중석의 한 사람.

■ 모으는 재미
· 엔딩 40여 종, 이벤트 200여 개, 레전드 카드.

이 게임의 인물·구단·대회는 모두 패러디이며, 실존 인물·단체와 관계가 없습니다. 나오는 사건은 전부 지어낸 이야기입니다.
```

## 5. 앱 콘텐츠 설문 답안

- **개인정보처리방침 URL**: `https://hanlok007-stack.github.io/kangin-raising/privacy.html` (웹 배포 후 열린다)
- **광고 포함 여부**: 지금 버전은 "아니요". 실제 광고(AdMob)를 붙인 버전을 올릴 때 "예"로 바꾼다.
- **앱 액세스 권한**: 모든 기능을 로그인 없이 쓸 수 있음.
- **데이터 보안**: 수집하는 데이터 없음, 공유하는 데이터 없음. (진행 상황은 기기 안에만 저장)
- **타겟층**: 만 13세 이상을 권한다. 어린이를 대상에 넣으면 가족 정책 심사가 추가된다.
- **콘텐츠 등급(IARC) 설문**: 폭력 없음 · 성적 내용 없음(연애 이야기는 있으나 선정적 묘사 없음) · 욕설 없음 · 약물 없음 · 도박 없음 · 이용자 간 소통 없음 · 위치 공유 없음 · 디지털 상품 구매는 지금 버전 "없음".
- **뉴스 앱 / 정부 앱 / 금융 기능 / 건강 기능**: 모두 해당 없음.
- **개발자 연락처 이메일** **[직접]**: 스토어에 공개된다. 공개해도 되는 주소를 쓴다.

## 6. 올리기 **[직접]**

1. 테스트 → 비공개 테스트 → 새 버전 만들기 → `kangin-release.aab` 업로드.
2. "Play 앱 서명" 사용에 동의한다(권장. 업로드 키를 잃어버려도 재설정할 수 있다).
3. 테스터 12명 이상 추가 → 14일 뒤 프로덕션 액세스 신청 → 프로덕션 출시.

## 7. 알아 둘 위험

- **실존 인물 패러디**: 이름을 비틀었어도 누구인지 알 수 있는 실존 선수가 주인공이다. Play의 명의 도용·지식재산권 정책이나 당사자·구단의 요청으로 심사에서 거절되거나 내려갈 수 있다. 특히 **유료 상품(광고 제거 9,900원)을 붙이기 전**에는 전문가에게 한 번 확인받는 편이 안전하다.
- **글꼴**: 화면 글꼴(Jua)을 인터넷에서 받아 온다. 오프라인에서는 기본 글꼴로 보인다. 앱 안에 글꼴 파일을 넣으면 해결된다.
