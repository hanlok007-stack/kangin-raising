# 이강인 키우기 — GDD v0.2

v0.1(1차 기획서)을 게임 디렉터·시스템 디자이너 관점에서 검토하고, MVP에 맞게 고친 문서.
v0.1에서 바뀌지 않은 내용(전체 커리어 구상, 30+ 엔딩, 이적·대표팀·SNS 등)은 장기 로드맵으로 유지한다.

## 1. v0.1 검토 — 8가지 질문에 대한 답

**Q1. 재미가 부족할 수 있는 부분**
- 1턴 = 1개월이면 유소년기(6~17세)만 144턴이다. 매달 같은 훈련 메뉴를 고르는 구간이 길어져 "숫자 올리기 노동"이 된다.
- 능력치 30여 개 + 숨김 11개는 선택의 결과를 읽을 수 없게 만든다. 훈련을 골랐을 때 뭐가 달라졌는지 한눈에 보여야 한다.
- 경기가 자동 시뮬레이션뿐이면 훈련의 보상이 체감되지 않는다. 훈련 → 경기 속 "결정적 순간"의 성공률로 직결되어야 한다.
- 피로·스트레스·행복도가 따로 놀면 "쉬어야 하나?"의 판단이 흐려진다.

**Q2. 반복 플레이 장치**
- 회차마다 달라지는 숨김 잠재력(PA)과 랜덤 이벤트 풀.
- 도감(이벤트·엔딩 수집)과, 엔딩 수집 개수로 해금되는 **회차 특전**(다음 회차 시작 보너스).
- 엔딩 화면의 **세계선 이탈률**과 **나비효과 타임라인** — "다른 선택을 했다면?"을 직접 자극.
- 한 회차 20~30분, 즉시 재시작.

**Q3. 능력치 과잉·중복** → 30개를 **성장 스탯 6 + 게이지 2 + 관계 4 + 숨김 4**로 압축.

| v0.1 | v0.2 |
|---|---|
| 드리블, 볼컨트롤, 민첩성 | **드리블** |
| 패스, 시야, 세트피스 | **패스** |
| 슈팅, 약발 | **슈팅** (왼발은 고정 특성으로 판정 보너스) |
| 스피드, 근력, 체력, 부상저항 | **피지컬** |
| 축구지능, 창의성 | **축구지능** |
| 멘탈, 승부욕, 자기관리, 프로의식, 리더십 | **멘탈** |
| 피로도 / 스트레스, 행복도 | **체력** / **스트레스** 게이지 |
| 감독 신뢰, 동료 관계, 팬 인기+인지도+언론 평판, (가족) | **감독 · 동료 · 인지도 · 가족** |
| 숨김 11종 | **잠재력(PA) · 부상 위험 · 향수병 · 외국어** (+ 플래그) |

자산·대표팀 위상·에이전트 신뢰도 등은 프로 커리어 단계에서 다시 도입한다.

**Q4. 계속 의미 있는 결정을 하게 하려면**
- 매 턴 **행동 3칸**: 훈련을 넣을수록 체력이 깎이고 스트레스가 쌓인다. 체력이 낮으면 훈련 효율이 떨어지고 부상 위험이 오른다 → 매 턴 "성장 vs 관리" 긴장.
- 나이에 따라 행동 메뉴와 고정 스토리 이벤트가 바뀐다(막축구는 13세까지, 경기 분석은 9세부터 등).
- 약 1~2년마다 세계선을 가르는 **분기 이벤트**(축구 지속, 팀 선택, 스페인행, 포지션, 감독 갈등, 빅클럽 접근, 계약).
- 감독 신뢰가 낮으면 벤치에 앉아 경기 기회 자체가 사라진다 → 관계도 자원이다.

**Q5. FM 축소판이 되지 않는 정체성**
- 팀이 아니라 **한 사람의 인생**을 다룬다. 전술판·스쿼드 화면이 없다.
- **세계선**: 실제 커리어는 "기준 세계선"일 뿐. 핵심 선택마다 실제와 같았는지 기록해 이탈률(%)로 보여준다.
- **나비효과 가시화**: 과거 선택이 만든 플래그가 현재 이벤트·선택지를 열면 "🦋 2010년 「스페인어 학습지」의 영향"처럼 출처를 표시한다.
- 톤: 축구 70 / 인터넷 문화 20 / 황당 10.

**Q6. 플래시 육성게임의 중독성**
- 한 턴 30초 내외, 클릭 3~5번이면 끝난다.
- 숫자가 튀어오르는 즉각 피드백, 10% 확률의 **각성(훈련 대성공)**.
- 성공률 %를 숨기지 않는다 — 도박의 맛.
- 황당 이벤트, 댓글, 엔딩 수집, 칭호.

**Q7. MVP 구현/제거**
- 구현: 분기 턴, 행동 3칸, 성장·체력·스트레스·부상, 결정적 순간 경기, 이벤트 엔진(고정/연쇄/조건부/랜덤), 뉴스+댓글, 인물, 세이브, 도감, 회차 특전, 엔딩·커리어 점수.
- 제거(이후 Phase): 이적시장, 구단 세부 속성, 재정, SNS 독립 시스템, 연애, A대표팀·병역, 전술.

**Q8. 엔진/콘텐츠 분리**
- `src/engine`: 규칙만 안다. 스탯 이름·이벤트 내용·주인공을 모른다. 순수 함수 `(pack, state) → state`.
- `src/data/<캐릭터>`: **캐릭터 팩** 하나가 한 게임. 스탯 정의, 초기값, 성장 곡선, 스테이지, 행동, 경기 장면, 이벤트, 엔딩, 인물, 특전, 텍스트가 전부 데이터.
- `src/ui`: 팩과 상태를 그리기만 한다.
- 주인공 교체 = 팩 폴더 하나 추가. 팩은 함수 없이 JSON으로 직렬화 가능한 구조만 쓴다.

## 2. MVP 범위

2007년(만 6세, 「날아라 슛돌이」) → 2018년 말(만 17세, 프로 계약 직전).
**1턴 = 1분기**, 총 48턴, 플레이 20~30분.

콘텐츠: 이벤트 60+, 행동 16종(훈련 10 + 생활 6), 경기 장면 14종, 인물 10명, 엔딩 13종, 회차 특전 6종.

## 3. 턴 구조

```
일정 짜기(행동 3칸) → 훈련 결과 → 경기: 결정적 순간 → 이벤트 → 분기 마감(회복·표류) → 다음 분기
```

- **훈련 성장량** = 기본치 × 나이 배율 × (PA/175) × 시설 × 적성 × 포지션 보너스 × 컨디션 × 한계 감쇠 × 난수(±15%)
  - 나이 배율: 10세 이하 ×2.0 → 18세 ×1.3 (이후 25세 ×1.0, 31세 ×0.6, 34세 ×0.3)
  - 컨디션 = 0.55 + 0.45 × 체력/100, 스트레스 70 초과 시 ×0.8
  - 한계 감쇠 = 1 − (현재치 / (PA/2+2))² — PA가 낮으면 일찍 정체된다
- **체력 25 미만에서 격한 훈련** → 부상 위험 누적. 부상 위험 60 이상이면 부상 이벤트가 터질 수 있다.
- **스트레스 95 이상** → 번아웃 경고 → 두 번째는 엔딩 위기.
- **판정 성공률** = 50% + (관련 스탯 가중평균 + 특성 + 컨디션 − 난이도) / 45, 5~95%로 제한.
  난이도는 소속 스테이지 수준과 체류 연수에 따라 오른다(스페인 아카데미가 가장 높고 시설 보너스도 가장 크다).

## 5. 분기 이벤트 (세계선)

슛돌이 오디션 → 종영 후 진로(계속/방송/그만둠) → 팀 선택 → 첫 감독 → 첫 라이벌 → 스페인어 학습지 → **스페인으로 가자** → 입단 테스트 → 언어 장벽 → 향수병 → 포지션 결정 → 첫 부상 → 첫 국제대회 → 새 감독과의 갈등 → 에이전트 → 연령별 대표 → 월반 → 빅클럽 접근 → 1군 호출 → **프로 계약**

## 6. 엔딩 (13종)

S 빅클럽 하이재킹 · S 메스타야의 왼발(REAL ROUTE) · A 왼발의 신 · A K리그 최연소 준프로 · B 하부리그 임대 · B 예능 신동 · B 축구하는 수재 · B 대학 축구의 별 · C 방출과 귀국 · C 조기축구회의 전설 · C 평범한 삶 · D 번아웃 · D 부상으로 사라진 천재

엔딩 화면: 커리어 점수(100점), 칭호, 기록, 숨김 PA 공개와 달성률, 세계선 이탈률, 나비효과 타임라인.

## 7. 콘텐츠 원칙

- 주인공 외 등장인물은 전부 가상 인물이다.
- 실존 인물에 대한 명예훼손, 확인되지 않은 사생활, 루머를 쓰지 않는다.
- 타이틀 화면에 "팬메이드 패러디 픽션" 고지를 둔다.

## 8. 이후 로드맵

MVP 재미 검증 → 프로 커리어(19~35세, 월 단위 턴 + 이적·구단) → 대표팀·병역 → 은퇴 후 엔딩 → SNS → 다른 주인공 팩.
