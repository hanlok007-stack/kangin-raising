# 이강인 키우기

2000년대 플래시 육성게임의 구조를 빌린 축구선수 육성 시뮬레이션. 2007년 「날아라 슛돌이」의 여섯 살 꼬마를 맡아 은퇴(만 35세)까지 키운다. 이강인을 프로에 데뷔시키면 손흥민·박지성 편이 열린다. 실제 커리어는 하나의 기준 세계선일 뿐이고, 선택에 따라 전혀 다른 인생이 만들어진다.

> 팬이 만든 패러디 픽션입니다. 주인공 외 등장인물과 사건은 모두 지어낸 것이며, 실제 인물·구단·단체와 관계가 없습니다.

플레이: https://hanlok007-stack.github.io/kangin-raising/

## 실행

```bash
npm install
npm run dev     # http://localhost:5180
npm test        # 데이터 무결성 + 자동 플레이 시뮬레이션
npm run build   # dist/ 에 정적 파일 생성
```

## 배포 (GitHub Pages)

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 테스트 → 빌드 → 배포를 한다.
저장소 Settings → Pages → Source를 **GitHub Actions**로 한 번만 바꿔 두면 된다.
빌드 결과물은 상대 경로(`base: './'`)라서 어떤 정적 호스팅(Netlify, Vercel, Cloudflare Pages)에 `dist/`를 올려도 그대로 동작한다.

## 게임 구조

- **턴**: 유소년(만 17세까지)은 반기, 만 18~29세는 분기, 서른부터는 다시 반기. 반기 턴에는 이벤트가 두 번까지 온다. 화면 상단에 "만 N세 · 상반기/N분기"와 커리어 진행률이 표시된다.
- **의욕**: 훈련만 시키면 의욕이 떨어지고, 아이가 딴마음을 먹는다("태권도 선수가 될래요"). 허락하면 전혀 다른 인생의 엔딩.
- **일정**: 분기마다 훈련·생활 행동 3개. 같은 훈련을 반복하면 경기에서 쓸 **기술**을 배운다(스루패스, 감아차기, 플립플랩 등 20종).
- **경기**: 분기마다 결정적 순간 2개. 상황에 맞는 기본기와 배운 기술 중에서 고르고, 끝나면 **경기 기록지**와 **평점**이 나온다. 평점이 감독 신뢰·인지도·대표팀 입지를 움직인다.
- **숨은 손익비와 선수 등급**: 경기 선택지에는 성공률만 보인다. 어려운 기술일수록 성공했을 때 평점과 등급 점수가 크게 오르고 실패하면 그만큼 깎인다. 등급은 유망주 → 주전급 → 리그 정상급 → 월드클래스 → 레전드.
- **연봉과 계약**: 프로가 되면 해마다 첫 턴에 연봉 협상을 한다. 제시액은 등급·리그·인지도·나이로 정해진다. 계약이 끝나는 해에는 FA 시장에 나온다.
- **에이전시**: 감독 면담, 월반·이적·임대 요청, 구단주 미팅, 언론 플레이, 시장 평가, 잔류 선언 등. 일정 칸을 쓰지 않지만 한 턴에 하나, 크게 얻거나 크게 잃는다. 프로 구간에서는 두 분기마다 에이전시 미팅이 일정보다 먼저 온다.
- **이적 시장**: 세계 지도를 펼쳐 유럽·아시아·중동·오세아니아·아메리카의 구단 15곳(지어낸 이름, 리그는 실제 이름)으로 옮길 수 있다. 돈을 많이 주는 리그와 무대가 큰 리그가 다르다.
- **관계**: 감독·동료·가족 수치가 바닥이면 위기가 터진다(2군 통보, 패스가 오지 않는다, 축구 금지령). 프로의 자리는 가만히 있으면 식는다.
- **애인**: 이강인 편에만 있다. 돌보지 않으면 떠나고, 곁에 있으면 슬럼프를 버티게 해 준다. 다른 선수 편에는 넘어가지 않는다.
- **황금 루트**: 조건이 어디에도 적혀 있지 않은 최고 엔딩. 단서 일곱 개를 한 판에서 모두 채워야 열린다.
- **이벤트**: 210여 개. 스토리(정해진 시기), 자동(상태·반복 행동이 부름), 랜덤, 연쇄. 이벤트마다 삽화가 붙는다.
- **대표팀·병역**: 아시안게임 금메달·올림픽 메달로 병역특례(예술·체육요원)를 얻는다. 월드컵에는 병역 혜택이 없다.
- **세계**: 동갑내기 추정 순위, 시장가치, 리그 사다리, 같은 나이의 실제 세계선과 비교.
- **엔딩**: 이강인 41종. 도감에서 이벤트와 엔딩 수집률을 본다. 엔딩을 모으면 회차 특전이 열린다.
- **레전드 도감**: 실제 역사에 남은 순간(월드컵 골, 클럽 입단 등)을 다시 만들면 선수별 카드가 열린다. 3명 × 13장.
- **되돌리기**: 도중에 망했을 때 광고(지금은 자리 표시)를 보고 그 턴의 시작으로 한 번 돌아갈 수 있다.

## 코드 구조

```
src/engine/       규칙. 스탯 이름도 이벤트 내용도 모른다. (pack, state) → state 순수 함수
  engine.ts       턴 진행, 훈련, 경기, 이벤트 선택, 관문, 점수, 세계 순위
  validate.ts     팩 무결성 검사 (테스트와 편집자 화면이 같이 쓴다)
src/data/kangin/  캐릭터 팩. 전부 JSON으로 직렬화 가능한 데이터
  actions.ts      훈련·생활·에이전시 행동
  match.ts        경기 기술과 장면
  story.ts pro.ts 스토리 이벤트 (유소년 / 프로·대표팀·병역)
  chain.ts        에이전시·행동 반복·위기 이벤트
  career.ts       선수 등급, 연봉 협상·FA·이적 시장 이벤트, 세계 구단, 황금 루트 단서
  nation.ts       대표팀의 갈등과 결정적 순간
  bonds.ts        감독·동료 관계 위기
  romance.ts      애인 (이강인 편 전용)
  random.ts       랜덤 이벤트
  art.ts          이벤트별 삽화
  endings.ts world.ts
  custom.json     편집자 화면에서 내보낸 데이터를 넣는 곳
src/ui/           화면
```

선수 팩은 `src/data/index.ts`에 등록한다. `son.ts`·`park.ts`처럼 고유한 것(스테이지, 스토리, 관문, 엔딩, 연표)만 쓰고
`derive.ts`의 `legend()`에 넘기면 훈련·경기 기술·일상 이벤트는 이강인 팩에서 물려받는다.

## 웹앱(PWA)과 앱 출시 준비

- 모바일 브라우저에서 "홈 화면에 추가"로 설치된다. 설치하면 가로 화면으로 열리고 오프라인에서도 실행된다(`public/manifest.webmanifest`, `public/sw.js`).
- 휴대폰 가로 화면에서는 왼쪽에 선수, 오른쪽에 진행 패널이 놓인다. 세로로도 플레이할 수 있다.
- 아이콘은 `npm run icons`로 다시 만든다(`scripts/make-icons.cjs`).
- 안드로이드 앱(Capacitor, `android/`): `npm run app:key`(서명 키, 한 번만) → `npm run app:release`(APK와 AAB 빌드). 스토어 등록 순서와 문구는 `docs/STORE.md`.
- 개인정보처리방침: `public/privacy.html` (배포하면 `/privacy.html`로 열린다).
- 광고: 게임은 `src/platform/ads.ts`의 `rewarded()`만 부른다. 지금은 3초 기다리는 자리 표시이고, 출시할 때 이 파일에서 AdMob 호출로 바꾼다.

## 편집자 화면

타이틀 로고를 일곱 번 누르고 PIN을 넣으면 관리자 설정이 열리고, 거기서 편집자 화면으로 들어간다. 이벤트 카테고리(아이콘·색·빈도 배율)와 이벤트(본문, 삽화, 발생 방식, 조건, 선택지)를 고칠 수 있다.

- **저장**: 그 브라우저에만 적용된다.
- **모두에게 적용**: "JSON 내보내기"로 받은 `custom.json`을 `src/data/kangin/custom.json`에 덮어쓰고 푸시한다.

밸런스는 `src/data/kangin/index.ts`의 `gainScale`·`growth`·`pa`(성장), `matchHard`(경기 난이도), `checkHard`(이벤트 판정 난이도)로 조절한다.
